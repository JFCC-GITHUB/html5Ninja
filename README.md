# 忍者手裏劍 (Pixel Ninja Defense / Shuriken Hero)

一款基於 HTML5 Canvas 的經典 2D 像素風忍者動作遊戲。

## 🎮 遊戲玩法與特色

- **中央忍者防守**：忍者站在畫面中央區域，隨時準備應對兩側襲來的敵人。
- **手裏劍射擊與 ⚡ 能量系統**：
  - 忍者可向左或向右投擲手裏劍擊殺敵人。
  - 每次投擲手裏劍需消耗能量（Energy），能量隨時間自動恢復。若能量用盡將暫時無法發射，增加策略控能的趣味度。
- **📈 漸進關卡與動態難度**：
  - 隨著遊戲時間與生存時間推進，關卡等級 (LV) 會持續提升。
  - 關卡越高，敵人出現頻率越密、移動速度越快，給予玩家極致挑戰。
- **多種敵人類型與難度選擇**：
  - **普通忍**：標準移動速度與 1 點生命值。
  - **疾風忍**：高移動速度，考驗反應力。
  - **重裝忍**：高血量 (3 HP)，需要多次命中才能擊倒。
  - **難度選項**：簡單 (Easy)、普通 (Normal)、困難 (Hard) 以及極限的地獄 (Extreme) 模式。
- **音效與粒子特效**：包含 Web Audio API 合成的懷舊 Sound Effects、升級提示聲及打擊/死亡粒子效果。
- **跨平台支援**：支援電腦鍵盤控制與手機/平板觸控（左右螢幕區域點擊）。
- **最高分記錄**：使用 LocalStorage 自動保存歷史高分紀錄。

## 🕹️ 操作說明

- **電腦 (Desktop)**:
  - 移動：`A` / `D` 或 ⬅️ / ➡️
  - 射擊手裏劍：空白鍵 `Space` (向目前面向的方向發射) 或 點擊對應方向鍵時自動轉向射擊
  - 暫停：`P` 或 `Esc`
- **手機/平板 (Mobile)**:
  - 點擊螢幕左側：向左轉/移動並射擊手裏劍
  - 點擊螢幕右側：向右轉/移動並射擊手裏劍

## 🚀 如何運行

直接在瀏覽器中開啟 `index.html` 即可遊玩，或使用任何靜態 Web 伺服器託管（例如 Python `http.server` 或 Live Server）。
